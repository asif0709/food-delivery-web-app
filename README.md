# Food Delivery Web Application

A responsive food-delivery web application developed as a practical full-stack learning project.

## What I worked on

- Responsive pages for browsing food and menus
- Cart and order-related user flows
- Java-based backend functionality for application data and CRUD operations
- MySQL database integration
- SQL queries, joins and structured database operations
- JavaScript validation and interactive UI behaviour
- Object-oriented Java code and exception handling

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Java
- MySQL
- SQL

## Project focus

The project was built to practise connecting a web interface with backend logic and a relational database while keeping the application structure simple and maintainable.
